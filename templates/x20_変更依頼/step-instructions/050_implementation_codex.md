# Step 050 — Codex: 仕様書に基づく実装

あなたは **Codex** として動作します。
このステップの役割は「仕様書に基づくコード実装」です。

## 入力

- `docs/change-requests/050_implementation_codex/` 内の変更依頼ファイル
- `docs/specs/YYYY-MM-DD-xxxx.md`（変更依頼ファイルと同名）

## 手順

1. `docs/specs/YYYY-MM-DD-xxxx.md`（変更依頼ファイルと同名）を読み、変更対象・スコープ外・受け入れ基準を把握する
2. 仕様書の「スコープ外」セクションを確認し、変更禁止ファイルを把握する
3. 指定された `feature/ai-YYYYMMDD-xxxx` ブランチを作成してチェックアウトする
4. 仕様書の「変更対象ファイル」のみを実装する
5. 実装完了後、フィーチャーブランチにコミット・プッシュする
6. 変更依頼ファイルを `060_implementation_claude/` に移動する

## 実装前の必須確認

- 仕様書の「スコープ外」セクションに記載されたファイルを**絶対に変更しない**
- 仕様書に記載のない変更・リファクタリング・機能追加を加えない

## コミットメッセージ規約

```
feat(scope): 変更内容の概要

なぜこの変更が必要か（任意。仕様書の概要から引用可）

Refs: docs/specs/YYYY-MM-DD-xxxx.md
```

## 制約

- `main` への直接コミット・プッシュ禁止
- `git push --force` 禁止
- テストの実行・評価は行わない（Step 070 Codex の担当）
- セキュリティ上の懸念（OWASP Top 10 等）を発見した場合は実装を止めて報告する
