# Step 100 — Claude: 仕様書・ドキュメント更新

あなたは **Claude** としてドキュメント更新を担当します。
このステップの役割は「実装内容に合わせたドキュメントの同期」です。

## 入力

- 変更依頼ファイル（プロンプトで**絶対パス**として渡されます）
- `docs/specs/YYYY-MM-DD-xxxx.md`（変更依頼ファイルと同名）

> **パス解決の注意（重要）**  
> Claude は worktree ディレクトリで起動されます。カレントディレクトリからの相対パスは使えません。  
> プロンプトで受け取った変更依頼ファイルの絶対パスを基点に、すべてのパスを導出してください。  
>
> 例: 入力が `/path/to/project/x20_変更依頼/change-requests/100_docs_claude/2026-06-04-xxx.md` の場合  
> - 移動先: `/path/to/project/x20_変更依頼/change-requests/110_pr_claude/2026-06-04-xxx.md`

## 手順

1. `docs/specs/YYYY-MM-DD-xxxx.md`（変更依頼ファイルと同名）を読み、今回の変更内容・スコープを把握する
2. 以下のドキュメントを実装内容に合わせて更新する

| 対象ドキュメント | 更新内容 |
|---|---|
| `docs/specs/YYYY-MM-DD-xxxx.md` | 変更した機能の仕様書を最終状態に更新 |
| `README.md` | 機能追加・変更があれば概要・使い方を更新 |
| `AGENTS.md` | Codex 向けのコマンド・規約に変更があれば更新 |

3. 変更依頼ファイルを `x20_変更依頼/change-requests/110_pr_claude/` に**絶対パスで**移動する
4. 更新内容をフィーチャーブランチにコミットする

## コミットメッセージ規約

```
docs: ドキュメントを実装内容に同期

Refs: docs/specs/YYYY-MM-DD-xxxx.md
```

## 制約

- このステップでは**コードを変更しない**（ドキュメント更新のみ）
- `main` への直接コミット禁止
- 仕様書の「スコープ外」に記載されたファイルのドキュメントは変更しない
