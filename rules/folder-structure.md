# フォルダ構成規約

## 基本方針

- プロジェクトルートに `src/` を置き、すべてのソースコードをその下に格納する
- テストコードはソースと同階層に `__tests__/` または `*.test.*` で配置する
- 設定ファイル類はプロジェクトルート直下に置く

## 標準ディレクトリ構造

```
project-root/
├── src/               # ソースコード
│   ├── components/    # UI コンポーネント（フロントエンドの場合）
│   ├── services/      # ビジネスロジック / 外部サービス連携
│   ├── models/        # データモデル・型定義
│   └── utils/         # 汎用ユーティリティ
├── tests/             # テストコード（src 外に置く場合）
├── docs/              # ドキュメント
├── scripts/           # ビルド・運用スクリプト
├── .claude/           # Claude Code 設定（git 管理外）
├── CLAUDE.md          # Claude Code ルール
└── README.md          # プロジェクト概要
```

## ルール

1. **深さは最大 4 階層**まで。それ以上になる場合はモジュール分割を検討する
2. **ディレクトリ名は kebab-case**（例: `user-auth/`, `api-client/`）
3. **index ファイルでの再エクスポート**は各ディレクトリに 1 つまで
4. **一時ファイル・生成物**は `.gitignore` に追加し、`dist/` または `build/` に出力する
