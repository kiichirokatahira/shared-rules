# 外部システム接続ルール

## 基本方針

- 接続情報（URL, 認証情報）は**環境変数**で管理し、コードにハードコードしない
- シークレット類は `.env` ファイルに記載し、必ず `.gitignore` に追加する
- `.env.example` をリポジトリに含め、必要な変数名と説明を記載する

## 環境変数の命名規則

```
{SERVICE}_{TYPE}
```

例:
- `DATABASE_URL`
- `REDIS_HOST`, `REDIS_PORT`
- `OPENAI_API_KEY`
- `SLACK_WEBHOOK_URL`

## 接続設定ファイルの構成

```
project-root/
├── .env               # 実際の値（git 管理外）
├── .env.example       # 変数名とコメントのみ（git 管理）
└── src/
    └── config/
        └── index.ts   # 環境変数を読み込み・バリデーションする単一エントリポイント
```

## 接続設定のルール

1. **接続設定は `src/config/` に集約**し、各モジュールが直接 `process.env` を参照しない
2. アプリ起動時に**必須変数の存在チェック**を行い、不足時はエラーで停止する
3. タイムアウト値は必ず設定する（デフォルト: HTTP 30秒、DB 10秒）
4. リトライ処理は**指数バックオフ**を使用する（最大 3 回）
5. 外部 API キーは定期的にローテーションする（最低年 1 回）

## セキュリティ要件

- 本番環境の認証情報は開発者個人の PC に保存しない
- API キーのログ出力は禁止（マスキング処理を入れること）
- 接続先 URL の変更は必ずレビューを通す
